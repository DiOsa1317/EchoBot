# 🤖 UnitMaster Bot

### **UnitMaster** — это Telegram-бот для мгновенного перевода единиц измерения. Он поддерживает конвертацию валют, физических величин (длина, вес, температура) и спроектирован с упором на масштабируемую архитектуру.

## 💬 Примеры взаимодействия

### Сценарий 1: Перевод валют
> **User:** `100 usd to rub`  
> **Bot:** `100 USD = 9 250.50 RUB`

### Сценарий 2: Физические величины
> **User:** `5 km to miles`  
> **Bot:** `5 km = 3.10686 miles`

### Сценарий 3: Обработка ошибок
> **User:** `привет`  
> **Bot:** `Я пока умею переводить единицы. Попробуйте формат: [число] [откуда] в [куда]. Например: 10 kg to lbs`

---

## 🛠 Технологический стек
*   **Язык:** Java 25
*   **Сборка:** Maven
*   **API:** Telegram Long Polling API
*   **Тестирование:** JUnit 5

## 🚀 Roadmap: План развития

#### Проект будет развиваться поэтапно, от базовой логики к сложной интеграции:

### 1. Задача 1: Ядро конвертации
*   Разработка интерфейса `UnitConverter`.
*   Реализация базовых конвертеров: `CurrencyConverter`, `LengthConverter`, `WeightConverter`.
*   Настройка парсинга сообщений формата «число из_чего в_что».

### 2. Задача 2: Актуальные курсы валют
*   Интеграция с внешним API (ExchangeRate-API) для получения реальных курсов.
*   Реализация механизма кэширования данных для оптимизации запросов.

### 3. Задача 3: История действий
*   Внедрение хранения истории последних 5–10 конвертаций для каждого пользователя (использование `Map`).
*   Добавление команды `/history` для просмотра прошлых операций.

### 4. Задача 4: Вторая платформа (VK/Discord)
*   Рефакторинг архитектуры: создание абстрактного класса `BaseBot`.
*   Реализация адаптера для второй платформы (например, VK LongPoll) с использованием единой бизнес-логики.

### 5. Задача 5: Интерактивное меню
*   Внедрение `InlineKeyboardMarkup` для удобного выбора категорий конвертации.
